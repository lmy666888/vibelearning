## Features and architecture decisions
- Generic ExperimentPlugin<P,S,O,Q>, no required charge/mass/time/particle assumptions; state/query/observable schemas belong to the plugin. Rendering is separate. Static nonparticle tests/scaffold demonstrate the scientific boundary.
- `shared/experiments.json` is the canonical metadata/parameter/unit/action/preset/equation/capability manifest. Explicit known-ID factories reject unknown/duplicate IDs, missing registrations and unsupported versions; no user-driven dynamic imports. Old electric preset/control copies are checked for compatibility.
- Context v2 binds experiment ID/version, validated parameters/query, independent scientific state/observables and globally monotonic browser revisions. Deterministic FNV correlation IDs encode exact IEEE-754 input bits, sorted registered keys and UTF-8, normalizing zero. Only identity/version/parameters/query/revision are hashed; derived values are independently checked with numerical tolerance to avoid rounding-induced identity mismatch. The hash is not authentication or a signature.
- One generic `/api/v2/ai/{operation}` and frontend AI workflow serve both plugins. Operations explain, plan-action, generate-lesson, evaluate-observation reuse the adapter, shared two-slot admission, bounded bodies/responses, timeouts, language policy and safe errors. Selected server manifest constrains actions; client capabilities cannot invent operations. Display equations come from the registry rather than generated math.
- Four existing action variants and schema version 1 remain. Preview compares actual-current observables against the confirmed/reset target, validates all actions before a single mutation, and requires explicit human confirmation. Wrong experiment/version, stale revision, switch-away/back and disposed runtimes reject. Lessons carry experiment identity, reconstruct sequentially and confirm every step/restoration; incorrect/unclear observations retry, correct+continue may advance without a mastery claim.
- Electric plugin delegates to original analytical physics and wraps existing controls/Canvas/presets/authored lesson/baseline. Explicit `?context=v1` UI and old API contracts remain; lazy isolation prevents v2 runtime creation from affecting the old clock. Historical E2E assertions remain unchanged apart from selecting the documented compatibility URL.
- Switching policy: pause and discard old runtime, baseline/proposals/lesson; load defaults and new monotonic identity. Shared language stays selected. No silent cross-experiment restore.

## Lorentz physics and visualization
F=q(E+v×B), ax=(q/m)(Ex+vyBz), ay=(q/m)(Ey−vxBz). Centered Boris/Cayley velocity rotation with symmetric electric half-kicks and trapezoidal position; velocities are initialized and exposed at integer times, not hidden half-steps. Uniform-field limitation is explicit. Fixed timestep 0.0002–0.02 s, duration ≤20 s, at most 100000 steps and coupled |qB/m|h≤0.02. Finite checks and pure-magnetic speed-error limits are enforced; no silent clamp. Detailed equations, reference solution and tolerances: [physics verification](../physics-verification.md).

Five canonical presets: straight/no fields, electric only, positive magnetic, negative magnetic, crossed E/B, each with specific objective and expected behavior. Lorentz Canvas draws isotropic spatial scales, particle/trace, E arrows, B dot/cross, velocity and electric/magnetic/total force directions. Color/normalized-length conventions are explicit. Play/pause/reset, 0.25×/1×/2× speed, timestep/duration, controls, preset selection, trajectory clear and vector toggle work. RAF uses a bounded fixed-tick accumulator, hidden-tab pauses, ≤1000 substeps/frame and ≤2000 trace points. ResizeObserver/DPR checks keep backing resolution correct.

For nonzero E/B, radius uses velocity relative to E×B drift; the simple half-radius rule is for E=0/fixed speed. For neutral charge, acceleration is zero and charged-particle gyro/drift predictions are undefined. The table correctly distinguishes total Lorentz force from electric force. Power P_B=F_B·v=0 and integrated work W_B=∫F_B·dr=0 are separate canonical equations.

- Shared HTTP wrapper swallowed explicit validation HTTPException into generic 500; it now preserves safe 422/403 errors.
- Disposed runtime references and identical switch-away/back snapshots needed explicit active flags and global monotonic revisions; covered by regression tests.
- Lorentz before-preview must use actual current observables, not initial-time force; target preview explicitly resets.
- Fingerprinting rounded derived values risks cross-language rounding mismatches; final identity hashes exact input bits and verifies derived science separately.
- Pure-B circular visualization needs isotropic pixels/metre; fixed independent x/y scaling. Neutral-particle drift is now undefined, and crossed-field radius uses drift-relative velocity.

- Technical identifiers/LaTex and copied English concepts caused real language failures; corrected registry-aware language handling and model instructions, preserving explicit mismatch errors. Canonical equation presentation prevents generated power/work-symbol errors from becoming displayed authority.

## Known limitations and recovery status
Uniform nonrelativistic fields only. Error budget is bounded but phase is not exact; extreme supported pure-B phase lag can approach 0.034 rad, and trace drawing keeps only the last 2000 points. Model narrative/intent/feedback remains advisory and may err; script/identifier language checks are conservative heuristics, not semantic proof. V1 is a maintained compatibility surface, not silently rewritten into v2. The shared manifest must accompany backend deployment. FNV IDs are correlation, not signatures/authentication.

Browser-local session recovery is explicitly deferred to prioritize model/architecture correctness. Current switch policy discards old sessions and reload creates paused defaults; no keys, prompts, answers or numerical state are stored in browser storage. A future restore must version identities/schema, revalidate scientific/lesson state and require confirmation, never resume running automatically. Public deployment still requires authentication, server-owned sessions and global quota controls. No long-duration memory stress test was claimed.
