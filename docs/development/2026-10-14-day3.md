## Architecture decisions
Keep the existing pure frontend engine and store. Validate the exact camelCase SI contract; verify derived values and pass canonical state to the provider. Separate route, verification, prompt and HTTP adapter. Use plain JSON-mode Chat Completions, no framework/tools. Keep snapshots recursively frozen and results request-associated. Concurrency is per-process and local-only, not production authentication.
