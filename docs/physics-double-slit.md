# Double-slit interference — scientific contract

Registered `double-slit-interference` v1, physics / wave optics. Independent scalar monochromatic coherent Fraunhofer model, not an electromagnetic particle engine. Uniform ideal slits of width a and center separation d, observation y on a plane at L:

`sinθ=y/√(L²+y²)`; `I(y)/I(0)=cos²(πd sinθ/λ) sinc²(πa sinθ/λ)`; sinc(0)=1 with a small-argument stable branch. Screen-angle geometry is exact; `Δy≈λL/d` is explicitly only a central paraxial estimate. Envelope first zero is `L(λ/a)/√(1−(λ/a)²)`. Polarization, near-field propagation, finite coherence, detector response and obliquity corrections are neglected. Optional Fresnel propagation is deferred.

Units/bounds are canonical in shared/experiments.json: λ380–780 nm, d10–300 μm, a1–100 μm with a<d, L.5–10 m, screen half-range2–50 mm, ≤5000 detections, 10–2000 events/s, uint32 positive seed, display mode0/1. Enforce `(d+a)²/(λL)≤.1`; invalid configurations fail with a far-field explanation, and ratios >.05 display an approximation warning. Numeric SI limit comparisons allow only relative machine-epsilon unit-conversion error (no physical parameter clamping or output rounding). This fixes the binary64 representation of exactly 100 μm at an inclusive bound.

A 1001-point symmetric discrete screen grid is normalized over the selected finite window. Seeded LCG state `(1664525s+1013904223) mod 2³²` with u=(s+.5)/2³² samples a monotone CDF by bounded binary search. Same seed/parameters/count produce identical screen indices across Python/TS. Probability is conditioned on the window; not all emitted flux is represented. The renderer draws actual model intensity/fringes and seeded y positions. Horizontal spread of detection dots is a visual detector thickness only, not simulated 2D quantum motion. No quantum field/trajectory/measurement-collapse solver is claimed.

The optical apparatus is explicitly schematic (not to scale), while screen-position/intensity plots use physical y and computed intensity. Responsive DPR/pan/zoom changes the view, not the profile. Six presets cover wide/narrow separation, short/long wavelength, finite-width envelope and single-event accumulation, with objectives/expected behavior. One generic event-count runtime handles playback. AI context sends only compact statistics/51 histogram bins, not 5000 points or full intensity arrays; backend recomputes all authoritative statistics.

Independent tests: centered symmetry to1e−14, interference/envelope zeros from analytical phase relations <1e−25, exact screen-angle reference, central fringe approximation and λ/d scaling, normalized probability to1e−12, reproducible/different seeds, 5000-event histogram L1 <.15 and near-zero sample mean. Cross-runtime contexts and shared confirmed actions/lessons, scope/quota inheritance, pause restore and browser accumulation run separately. Histogram convergence is statistical, not guaranteed for every seed/count.

Primary reference: [OpenStax, Double-Slit Diffraction](https://openstax.org/books/university-physics-volume-3/pages/4-3-double-slit-diffraction). The implemented idealization and finite-window discretization are explicit above.
